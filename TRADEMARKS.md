## Why these names appear here

Printagent's skills read, write, and describe files for third-party CAD programs, slicers, and
printers. Naming those products is the only practical way to say what the software actually
interoperates with — a printer profile has to say which printer it describes, and a slicer
handoff has to say which slicer it targets. Every such reference is **nominative**: it identifies
the real product to describe compatibility, and nothing more.

Accordingly:

- No trademark is used as the name of this project, its plugin, or any product it produces.
- No use here is intended to suggest that a trademark owner produced, reviewed, approved, or
  supports Printagent.
- Some directories and files carry a product name (`slicing-handoff-bambu`,
  `publishing-onshape`, `air-sampling-cassette-4up-x1c.3mf`) purely to say which product the
  contents target. The name describes compatibility, not origin.
- `skills/reviewing-manufacturability-fdm/scripts/printer_profiles.json` records published
  physical specifications — bed dimensions and nozzle sizes — independently compiled as
  statements of fact. It contains no vendor configuration files, profiles, or other vendor
  content.
- Printagent bundles no vendor software or profile data. Where a skill needs a vendor's own
  settings, it reads them at run time from that vendor's application, already installed on the
  user's machine.

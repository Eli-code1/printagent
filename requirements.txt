# Python dependencies for the FDM Design Loop skills.
#
# Verified working set (macOS, Python 3.11):
#   build123d 0.11.1, trimesh 4.12.2, scipy 1.17.1, numpy 2.3.2, rtree 1.4.1,
#   bd_warehouse 0.3.0
#   (build123d pulls in cadquery-ocp 7.8.1.1 — the OCCT geometry kernel).
#
# bd_warehouse (same author as build123d) supplies thread/fastener generators;
# parts that model printed threads (e.g. parts/apollo-fan-tripod-sled/sled.py's
# 1/4-20 socket) import it. It requires build123d>=0.11.1.
#
# rtree is an optional trimesh extra, not a hard dependency of it — but
# reviewing-manufacturability-fdm's check_min_wall.py uses trimesh ray casting,
# which imports rtree at call time. Without it the gate crashes.
#
# networkx and lxml are likewise optional trimesh extras that its 3MF writer
# imports at call time; slicing-handoff-bambu's export_3mf.py crashes without
# them.
#
# shapely is another optional trimesh extra imported at call time — its
# section/slice-capping code (trimesh.path.polygons) needs it when the geometry
# skills cross-section parts. Without it those calls raise ModuleNotFoundError.
#
# NOTE: two of the six skills need NONE of these — `analyzing-print-failures`
# and `designing-in-plain-language` run on the Python standard library alone.
# Install the packages below only for the geometry skills (generating-build123d,
# reviewing-manufacturability-fdm, reviewing-structural-loads, slicing-handoff-bambu).

build123d>=0.11.1
trimesh>=4.12.0
scipy>=1.13.0
numpy>=1.26.0
rtree>=1.0.0
bd_warehouse>=0.3.0
networkx>=3.0
lxml>=5.0
shapely>=2.1
